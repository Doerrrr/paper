## 0. 切入点：当目标从"一条蛋白链"变成"任意分子组合"，AF2 的零件哪些还能用、哪些必须换？

这是全文的脊柱问题，后面每节回扣它。

AF2 的机器是**为蛋白质量身定做**的：MSA 主干、残基刚体框架、"为每个氨基酸预测侧链扭转角"。这套表示很美，但有一个致命的不对称——**小分子配体没有 MSA、没有"氨基酸残基"这种天然单元，核酸的天然单元是核苷酸而非残基侧链角**。所以 AF2 的"输入序列 → 残基框架 → 侧链角"链路，遇到"蛋白+DNA+配体+离子+糖基"的任意组合就卡住了。

AlphaFold3 的赌注可以用一句话概括：**关系推理可以通用，坐标表示不能通用。**

- **能通用的**：Evoformer 里那套"在残基对上做三角更新、维护一张成对关系图"的归纳偏置——它不关心你是蛋白还是配体，只关心"谁挨着谁"；
- **不能通用的**：把"结构"表示成"每个氨基酸一个刚体 + 一组侧链角"——这套只服务于蛋白，套不到配体上。

于是 AF3 做了一刀切式的解耦：**主干保留并简化成 Pairformer（继续做关系推理），坐标生成从"残基框架 + IPA"换成"全原子扩散去噪"**，从而所有实体——不管有没有 MSA、不管天然单元是什么——都共用同一个输出变量：原子坐标 $X\in\mathbb R^{N_{atom}\times3}$。

**一句话脊柱：AF3 不是"AF2 加个配体头"，而是"拆掉 AF2 的坐标专用件、保留其关系推理内核、换上能覆盖任意分子的原子级扩散生成器"。** 记住这条，下面所有改动（弱化 MSA、去 IPA、加扩散）才有动机。

![[figs/af3_fig1d_architecture.png]]
*Fig.1d（原文第 2 页）。这张图想让你看清整条信息流：输入 = 聚合物序列 + 配体 SMILES + 共价连接/修饰 → 嵌入 + MSA/模板特征 → 简化 MSA(4 块)+模板(2 块) → **Pairformer(48 块)** → **扩散模块去噪** → 完整复合物原子坐标 → 置信度 → 排序。注意底部"Recycling"和"Diffusion Iterations"是两个不同回路（下一节讲）。*

## 1. 论文真正主张什么（去宣传腔）

一句话：他们造了一个**统一模型**，输入"组成分子的序列 + 化学信息（配体 SMILES、修饰、共价连接）"，**直接输出蛋白质、核酸、配体、离子、修饰残基形成复合物的全原子坐标和置信度**，并在多类界面基准上明显超过专用对照。

主张的边界：它是**条件生成模型**——给定组成，输出一个（批一批的）空间排列，**不回答"这些分子在真实条件下是否真的结合"**，也不输出溶液构象系综（见第 6 节）。

几个 headline 数字（统一取自原文 Extended Data Table 1，以"成功 = 指标超过阈值"计）：

| 任务 / 指标 | AF3 | 主要对照 | 说明 |
|---|---:|---:|---|
| 蛋白质–配体，PoseBusters V1，口袋对齐后配体 RMSD<2Å | **76.4%** (n=428) | Vina 52.3% / RoseTTAFold All-Atom 42.0% | 不指定真实口袋；2019 截止模型防泄漏 |
| 蛋白质–双链 DNA，iLDDT | **64.8** (n=38) | RoseTTAFold2NA 28.3 | 跨链界面精度 |
| 蛋白质–RNA，iLDDT | **39.4** (n=25) | RoseTTAFold2NA 19.0 | 提升大但绝对数仍低 |
| 蛋白质–蛋白质，DockQ>0.23 | **76.6%** (n=1064) | AlphaFold-Multimer v2.3 67.5% | 链间界面 |
| 蛋白质–抗体，DockQ>0.23 | **62.9%** (n=65) | AF-M 29.6% | **用 1000 个种子排序**，非默认 5 种子 |

注意：**这些数字口径互不相同**（RMSD 成功率 vs iLDDT vs DockQ），不能把"76.4% 配体"和"64.8 DNA"直接比出"哪个任务更容易"。而且 90.2% 那个配体数字**是额外喂了真实口袋的专门配置**，不是标准盲预测，正文与表都做了隔离——别混进来。

## 2. 概念词典：先认全零件，再看怎么组装

**规则：下面架构走读与承重判定里出现的每个术语，先在这里定义。** "见图"指向 Fig.2 面板。

| 术语 | 一句话是什么 | 服务什么问题 | 类比 | 见图 |
|---|---|---|---|---|
| **token** | 网络处理的"单元"，可对应一个残基、一个核苷酸、或一个（配体的）原子 | 把不同天然单位的实体塞进同一张图 | 翻译时把"词"统一成 token，不论原文是单词还是汉字 | Fig.2a/b |
| **Pair 表示** $Z\in\mathbb R^{n\times n\times128}$ | 每对 token $(i,j)$ 的关系张量 | 编码"谁挨着谁、什么取向"的假设 | 一张不断修订的全局距离/接触草图 | Fig.2a 下 |
| **Single 表示** $S\in\mathbb R^{n\times384}$ | 每个 token 的上下文特征 | 单个单元的"状态" | 每个词在自己句子里的向量 | Fig.2a 上 |
| **MSA module**（4 块） | 先跑 4 个简化块从同源序列抽信息，**之后不再逐层保留完整 MSA** | 给主干喂进化共变，但不过度绑定蛋白假设 | 先做一次文献综述，之后只留结论 | Fig.2a 左 |
| **模板 module**（2 块） | 检索到的近缘已知结构作可选输入 | 提供现成参照（若有） | 允许带的一页参考答案 | Fig.2a 左 |
| **Pairformer**（48 块，不共享权重） | 主干：保留 Evoformer 的四种三角更新 + transition，single 分支用 pair-bias 注意力 | 纯做实体间关系推理，不再背着 MSA 走全程 | AF2 Evoformer 的"关系推理内核"，卸掉进化包袱 | Fig.2a |
| **pair-weighted averaging** | MSA→Pair 的廉价聚合（取代 AF2 的 Outer Product Mean 式重处理） | 把 MSA 信息压进 Pair 后，MSA 流就退休 | 把综述结论压缩成一页提要 | Fig.2a 左 |
| **扩散模块** | 从随机原子噪声出发，按条件逐步去噪生成 $X\in\mathbb R^{N_{atom}\times3}$ | 用**通用原子坐标**统一所有实体的输出 |  sculptor 从一团随机点云里"擦"出分子 | Fig.2b |
| **噪声尺度 $\sigma$** | 加噪/去噪的强度；训练时从 $\sigma_{max}$ 到 $\sigma_{min}$ 多尺度 | 大噪声学全局装配，小噪声学局部化学 | 先捏大形，再雕细节 | Fig.2b/c |
| **per-atom / per-token conditioning** | 去噪网络在原子级和 token 级分别读条件特征 | 兼顾"局部化学"与"全局关系" | 细看笔触 + 远看构图 | Fig.2b |
| **seq-local 注意力** | 按序列/索引局部组织的注意力（**不是**三维空间近邻注意力） | 局部化学信息交换 | 只看"前后几个词" | Fig.2b 标注 |
| **IPA（AF2 的）** | 局部框架不变点注意力 | AF2 的坐标更新算子 | —— | （AF2） |
| **mini-rollout（20 次迭代）** | 训练时用大步长跑一整条去噪生成完整结构，再算真实误差训练置信度模块 | 让置信度学会"推理时真会错多少" | 模拟考一次完整做题，再判自己哪错 | Fig.2c |
| **cross-distillation（跨蒸馏）** | 用 AlphaFold-Multimer v2.3 预测（常给松散延展构型）当训练目标 | 减少扩散模型把无序区"幻觉"成紧凑结构 | 请一个"习惯画松结构"的老师带节奏 | ED Fig.1 |
| **permute ground truth（对称匹配）** | 训练时把预测和真值按对称等价排列重新编号后再比对 | 避免"编号不同"被冤枉成结构错 | 先对齐座位号再判谁没来 | Fig.2c 右 |
| **pLDDT / PAE / PDE / ipTM** | 原子局可靠度 / 区间定位误差 / 距离误差 / 界面折叠可靠性 | 让使用者知道哪能信 | 各部位保修等级 | Fig.4a |
| **PoseBusters / DockQ / iLDDT** | 配体成功率 / 界面质量 / 界面局部距离精度 | 量化"准不准" | 不同口径考分 | Fig.1c/4/ED Table1 |

## 3. 网络架构解析：怎么搭的，为什么"换坐标件、留关系件"能成立

### 3.1 总数据流（对照 Fig.1d 读）

```
聚合物序列 ─┐
配体 SMILES ─┤→ 原子/token 嵌入 + 参考构象 + MSA/模板特征
修饰/共价连接 ─┘
        ▼
  简化 MSA module (4 块) + 模板 module (2 块)   ← 只在此处碰进化/模板信息
        ▼
  Pairformer × 48 块（只维护 Z 和 S）            ← 纯关系推理内核
        ▼
  扩散模块：随机原子坐标 ──(per-atom/token 条件去噪)──> 复合物原子坐标 X
        ▼
  Recycling：输出回灌主干（更新 Z/S，不重新去噪）
        ▼
  置信度模块 (pLDDT/PAE/PDE/ipTM) → 多种子多样本排序 → 最终候选
```

**关键区分**（正文一再强调）：**Recycling** 和**扩散去噪**是两个不同回路——
- Recycling：把第一次生成的结构当条件，再跑一遍主干去**更新抽象关系表示**（Z/S）；
- 扩散迭代：在固定条件下，从噪声**生成原子坐标**。
前者改"理解"，后者改"画"。

### 3.2 主干：从 Evoformer 到 Pairformer（Fig.2a 逐块走）

![[figs/af3_fig2a_pairformer.png]]
*Fig.2a（原文第 3 页）。这张图想让你看清 Pairformer 的两个减法：左——MSA 处理从"48 层逐层保留"压成"4 块后只留 pair-weighted averaging"，之后主干只带 Z、S；右——单/对表示在 48 个 block 里反复更新（pair 提供 bias 给 single 注意力，single 也回写 pair）。*

Pairformer 对 Evoformer 做了**保留内核、卸掉包袱**：
- **保留**：四种三角更新（outgoing/incoming 乘法更新 + starting/ending-node 三角注意力）+ transition——关系推理的核心没动；
- **改动**：pair/single 分支用 pair-bias 的注意力与 transition；
- **减法（最重要）**：原 Evoformer 在 48 层里**持续背着完整 MSA 表示**与 pair 双向交流；AF3 先用 **4 个简化 MSA block** 把共变信息抽出来、用廉价的 **pair-weighted averaging** 压进 pair 表示，**之后主干不再携带 MSA 流**，只维护 $Z$ 和 $S$。

**为什么敢这么减**：小分子配体没有可逐位对齐的进化 MSA，很多跨实体关系必须靠化学信息、结构训练、空间推理补齐。背着蛋白专属的 MSA 流反而拖累通用性。但注意——**MSA 没被删**（论文明说保留了检索），只是"不再逐层占用主干"。

### 3.3 坐标生成：从"残基框架 + IPA"到"全原子扩散"（Fig.2b）

![[figs/af3_fig2b_diffusion_module.png]]
*Fig.2b（原文第 3 页）。这张图想让你看清扩散模块的内部堆叠：3 个原子级局部注意力 → 24 个 token 级全局注意力 → 3 个原子级局部注意力；条件特征从主干来，噪声坐标从原子级注入。注意右下"NO IPA / NO residue frames"的意味——坐标生成机制重构了。*

AF2 用"每个氨基酸一个刚体框架 + 预测侧链角"；AF3 直接生成**原子坐标** $X\in\mathbb R^{N_{atom}\times3}$。好处是：不管你是蛋白残基、核苷酸还是配体原子，**输出变量只有一个**——不必为每类分子单独设计一套残基框架和侧链角表示。

扩散模块的内部是"局部–全局–局部"三段注意力：
- **3 个原子级局部注意力 block**：精细化学信息；
- **24 个 token 级全局注意力 block**：整合全局关系；
- **3 个原子级局部注意力 block**：把信息传回原子尺度。

训练 = 给真实坐标加噪、学恢复（机制示意）：

$$
X_\sigma = X^* + \sigma\epsilon,\qquad \epsilon\sim\mathcal N(0,I),\qquad
\widehat X^* = D_\theta(X_\sigma,\sigma;C)
$$

其中 $C$ 是输入化学特征与主干表示，$\sigma$ 是噪声尺度。**多尺度噪声**刻意让模型同时学两件事：

| 噪声尺度 | 主要恢复任务 | 对应能力 |
|---|---|---|
| 较大 $\sigma$ | 从严重扰动找回总体排列 | 全局折叠、分子相对位置、界面 |
| 较小 $\sigma$ | 修正小扰动 | 局部键几何、侧链与配体构象 |

### 3.4 为什么不再用 IPA / 显式等变（这是 AF3 最反直觉的一刀）

![[figs/af3_fig2d_learning_curves.png]]
*Fig.2d（原文第 3 页）。这张图想让你看清一个训练观察：链内指标（各类"自己折好"的精度）在前 ~20k 步就到 97%，而蛋白质–蛋白质界面 iLDDT 要到 >60k 步才到 97%——"局部几何"比"全局装配"学得早。注意 97% 是"相对初始训练最高指标的 97%"，不是"97% 准确率"。*

AF2 花了大力气把**旋转/平移等变性**硬编码进 IPA 与残基框架。AF3 正文明确写道（原文第 4 页）：

> "we find that no invariance or equivariance with respect to global rotations and translation of the molecules are required in the architecture and we therefore omit them to simplify the machine learning architecture."

并且还自曝了一处来自 AF2 的经验依据（原文第 3 页）：

> "We have observed in AF2 that removing most of the complexity of the structure module had only a modest effect on the prediction accuracy."

**白话**：AF3 用随机旋转/平移等数据增广手段，让网络自己学会对坐标变换不敏感，而不是把等变性写死在架构里——这样任意分子图都能建模，不必为每种实体定制刚体框架。**"AF3 沿用了 AF2 的 IPA 结构模块"是错的**；它保留了"关系推理"思想，但坐标生成机制已重构。

### 3.5 回扣切入点：什么被传承，什么被替换

| | AF2 | AF3 | 是传承还是替换 |
|---|---|---|---|
| 关系推理内核 | Evoformer（三角更新×4 + 双向 MSA↔Pair） | Pairformer（三角更新×4 保留，MSA 流卸掉） | **传承 + 简化** |
| 坐标生成 | 残基框架 + IPA + 侧链角（蛋白专用） | 全原子扩散去噪（通用） | **替换** |
| 等变性 | 硬编码（IPA/框架） | 数据增广隐式学 | **替换思路** |
| 置信度/排序 | pLDDT/PAE/pTM | 加 PDE/ipTM + mini-rollout 训练 | 扩展 |
| 任务范围 | 单链蛋白 | 蛋白/核酸/配体/离子/修饰复合物 | 大幅扩展 |

### 3.6 训练里的两个非显然技巧

![[figs/af3_fig2c_diffusion_training.png]]
*Fig.2c（原文第 3 页）。这张图想让你看清两件事：左——扩散训练是"加噪→去噪"的单步恢复，不是完整推理；右——置信度模块靠"20 次迭代 mini-rollout"生成完整结构、再做对称匹配（permute ground truth）算出真实误差来训练。图中 stop-gradient 标记说明这些步骤有梯度隔离。*

1. **mini-rollout（20 次迭代）**：普通扩散训练只训"单步恢复"，并不知道"完整跑一遍会错多少"。AF3 专门用大步长跑**完整一次生成**，再对结果算真实误差来训练 confidence module——否则置信度会"以为自己比实际准"。
2. **cross-distillation（跨蒸馏）**：用 AlphaFold-Multimer v2.3 的预测（常给松散、延展的链）当训练目标，帮 AF3 减少把无序区"幻觉"成紧凑折叠的倾向（ED Fig.1 在 CAID2 无序评测支持）。

## 4. 承重 vs 装饰：AF3 没有组件级消融表，这点要先说清

**重要诚实声明**：AF2 有 Fig.4a 那种"拔掉一个组件看掉多少分"的消融表；**AF3 正刊没有这样的组件级消融表**。它给的证据是**跨任务基准（ED Table 1）+ 训练曲线（Fig.2d）+ 采样/蒸馏分析（Fig.5a、ED Fig.1）+ 训练裁剪微调观察**。所以我这里的"承重判定"严格说分两类：**有对照证据的**，和**正文只陈述、未做组件消融的**——后者标注"未确立"。

| 组件/改动（词典已定义） | 判定 | 证据来源 | 白话 |
|---|---|---|---|
| **全原子扩散坐标生成** | **承重**（成立前提） | 多类界面基准超过专用对照 | 整篇模型成立就靠它统一输出；换回 AF2 式框架则无法覆盖配体/核酸 |
| **Pairformer 关系推理内核** | **承重** | 架构主体 + 基准支持；"卸掉 MSA 流"后仍靠它撑精度 | 三角更新这套"关系推理"是 AF2 遗产里真正被保留并验证的部分 |
| **置信度模块 + 排序** | **承重**（实用前提） | Fig.4a 校准：pLDDT/PAE/ipTM 与真实误差高度相关 | 没有它，生成式模型出的几百个候选没法筛 |
| **cross-distillation** | **贡献**（有证据） | ED Fig.1 CAID2：减少虚假紧凑结构 | 缓解无序幻觉，但没把 AF3 变成 IDP 系综预测器 |
| **弱化 MSA（卸主干 MSA 流）** | **贡献/已验证可行** | 正文观察 + 基准；但 MSA 深度仍影响精度（见 6） | 通用性换精度的取舍，已证明"可"，但"最优"未确立 |
| **大裁剪微调（384→640→768）** | **贡献（界面）** | 训练观察：界面精度随裁剪增大提升 | 但非单因素实验，不能隔离归因 |
| **多种子/多样本采样** | **贡献（显著，尤其抗体）** | Fig.5a：5→1000 种子持续提升 | 计算换精度；但默认 5 种子 ≠ 论文抗体 62.9% 的 1000 种子 |
| 三角更新单独保留 | **传承件，未做单独消融** | 无组件级对照；属"继承而非新证" | 不能因为 AF3 用了就说"被消融证明必要" |
| 去掉显式等变（IPA/框架） | **改动，正文称"modest 影响"** | 基于 AF2 经验陈述，非 AF3 独立消融 | 思路替换，代价大小靠数据增广弥补 |

**最容易被误读的一点**：很多报道把"AF3 全面超过 AF-Multimer"直接归功于"扩散"。论文本身没做这种单因素归因——**输入、训练数据、主干（Pairformer vs Evoformer+former）、任务覆盖、采样设置全变了**。所以从 AF2→AF3 的提升，**不能干净地归功于扩散一个零件**。

## 5. 公式落到具体数字

### 5.1 扩散加噪/去噪（机制示意，非完整训练算法）

$$
X_\sigma = X^* + \sigma\epsilon,\quad \epsilon\sim\mathcal N(0,I)
$$
$$
\widehat X^* = D_\theta(X_\sigma,\sigma;C),\qquad
\mathcal L_{\text{denoise}}\sim \mathbb E_{\sigma,\epsilon}\big[w(\sigma)\,\lVert\widehat X^*-X^*\rVert^2\big]
$$

**构造的小例子**（非论文数字）：一个 3 原子分子，真实坐标 $X^*=[(0,0,0),(1,0,0),(0,1,0)]$。取 $\sigma=0.5$，噪声 $\epsilon=[(0.1,0,0),(0,-0.2,0),(0.05,0.05,0)]$，则 $X_\sigma=[(0.05,0,0),(0.9,-0.1,0),(0.025,1.025,0)]$。网络从 $X_\sigma$ 学回到 $X^*$——$\sigma$ 大时这个例子会被扰动到"认不出形状"，逼模型先学"大致往哪摆"。**注意**：上式省略了真实实现里的坐标对齐、原子权重、对称性、stop-gradient 与多个辅助损失，不能直接当训练脚本用。

### 5.2 mini-rollout 为什么必要（一个反直觉点）

普通扩散单步损失只关心"这一步去噪对不对"，**不等于**"完整采样 20 步后结构对不对"。AF3 用一次 **20 步完整 rollout** 产出真实结构，再算真误差训练置信度——否则会出现"单步误差小、成品却错得离谱"。构造例子：一个模型每步只错 0.1Å，但 20 步累积漂移后整体折叠错 5Å；单步损失会打高分，rollout 误差才暴露。这就是为什么 Fig.2c 要专门画"mini-rollout"。

### 5.3 指标口径：为什么 76.4% 和 64.8 不能互比

- **PoseBusters 成功率**：口袋对齐后配体重原子 RMSD<2Å 的比例——是"配体摆对没"的二值题；
- **iLDDT**：逐残基层面"邻近接触保持度"，值域 0–100——是"界面局部距离准不准"的连续分；
- **DockQ>0.23**：界面质量达到"可接受"的二值比例。

三类量纲不同，跨任务比"谁更难"是 **无效比较**，论文和 ED Table 1 也都分任务列、不混排。

## 6. 证据边界：结果建立到哪儿，没建立到哪儿

![[figs/af3_fig4a_confidence_calibration.png]]
*Fig.4a（原文第 6 页）。这张图想让你看清：置信度指标（pLDDT、PAE、ipTM）与真实误差高度相关——高置信区真实精度确实高，低置信区确实易错。这是"可以用置信度筛候选"的基础，但它是"相关"不是"逐例保证"。*

![[figs/af3_fig5a_antibody_seeds.png]]
*Fig.5a（原文第 7 页）。这张图想让你看清：抗体预测精度随**模型种子数**从 5 涨到 1000 仍持续上升，且增加"每种子扩散样本数"解释不了同等增益——种子比样本更关键，但也更贵。所以 62.9% 是 1000 种子预算下的成绩，不是默认 5 种子。*

**支持结论的部分（较强）：**
- **PoseBusters 用 2019 截止模型** + 时间切分，降低数据泄漏（测试结构来自更晚时间）；
- **聚类级统计**：蛋白质–蛋白质 1064 个聚类、DNA 38、RNA 25，多数报告了样本数与置信区间；
- **置信度经校准验证**（Fig.4a）：指标与真实误差相关；
- **抗体做显著性检验**：论文用了 Fisher 精确检验比较 AF3 与 AF-M。

**未建立 / 要打问号的部分（最关键）：**
- **没有组件级消融表**（第 4 节已讲）——"扩散 vs 框架"的净贡献在正文层面**未确立**；
- **90.2% 配体不是盲测**：那是额外喂真实口袋的专门配置，不能并入标准 76.4%；
- **糖基化数字对筛选极敏感**：高质量糖基子集 72.1% vs 全质量单残基 46.0%、多残基 42.4%——评测条件主导数字；
- **手性违规 4.4%**：即便排序加入手性惩罚，仍有约 1/23 预测犯立体化学错，极端时同源多聚体整条链重叠碰撞；
- **随机样本 ≠ 溶液系综**：论文明确指出，改扩散头或整网种子**不会**得到 Boltzmann 构象近似——不能当 IDP/IDR 的构象系综用；
- **apo/holo 状态混淆**：E3 泛素连接酶案例，模型对 apo、holo 都偏预测闭合态，说明配体输入 ≠ 自动正确模拟诱导契合/变构；

![[figs/af3_fig5c_conformational_state.png]]
*Fig.5c（原文第 7 页）。这张图直接给 apo/holo 混淆的视觉证据：真实 ground truth（灰）在 apo 与 holo 两种状态结构不同，但 AF3（蓝）对两者都偏向预测同一闭合构象——"输入了配体"并不等于"自动正确模拟了状态转换"。*
- **结合结构 ≠ 结合强度/真实发生**：输出空间排列，不提供亲和力、自由能或细胞内是否真形成复合物；
- **MSA 深度仍敏感**：与 AF-M 一样，浅 MSA 目标更难（正文陈述，未见 Fig.5 那类专门曲线在 AF3 主文）；
- **静态结构学习未解决动态生物学**：不替代 MD、热力学或动态实验。

## 7. 该带走什么、什么仍然开放

**带走的（尤其对你 IDR/IDP 方向）：**
1. **脊柱答案**：AF3 = "拆掉坐标专用件、保留关系推理内核、换上通用原子扩散"。看到任何"扩展任务范围"的架构论文，都可问同一句："哪部分通用、哪部分必须按任务定制？"
2. **扩散 ≠ 更好，是更通用**：AF3 赢在"统一覆盖"，不是单点精度碾压；不能干净归因于扩散。
3. **对你最关键的一条**：AF3 多个随机样本**不是**溶液构象系综——它定义了条件分布 $X\sim p_\theta(X\mid\text{组成})$，但**不等于**物理分布 $p_{\text{physical}}(X\mid T,\text{pH},\text{溶剂,浓度})$。无序区靠 cross-distillation 缓解"幻觉紧凑结构"，但 AF3 仍不是 IDP 自由态采样工具——这正是你需要 IDPFold / STARLING 这类系综方法的原因（与 AF2 同源的限制）。
4. **置信度是筛候选的钥匙，不是保证**：高 ipTM 支持"这个界面可能靠谱"，但不证明两分子真结合。

**仍开放的：**
- 组件级净贡献（扩散 vs 框架）未消融；
- 静态结构 → 动态/自由能的跨越未解决；
- 无序区真实构象多样性未覆盖；
- 大复合物、稀有修饰、配体多样性的极限未探明。

## 8. 三代一句话对照

| | AF1 | AF2 | AF3 |
|---|---|---|---|
| 主干 | 2D 残差卷积 | Evoformer | Pairformer |
| 坐标生成 | 外部势函数优化 | 残基框架 + IPA（端到端） | 全原子扩散去噪 |
| 等变性 | — | 硬编码（IPA/框架） | 数据增广隐式 |
| 任务 | 单链折叠 | 高精度单链 | 多类生物分子复合物 |
| 共同边界 | 非物理轨迹 | 非完整系综 | 随机样本仍非真实系综 |

三代演进：**学习几何约束 → 端到端几何推理 → 统一多类分子的原子生成。**
