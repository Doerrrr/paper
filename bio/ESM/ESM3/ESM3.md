# ESM3 论文创新点

论文题目：*Simulating 500 Million Years of Evolution with a Language Model*

ESM3 的目标是：把蛋白质的序列、三维结构和功能统一表示为离散 token，在同一个双向 Transformer 中进行条件预测和生成，使用户能够使用任意一种或多种模态作为提示，补全并设计新的蛋白质。

论文最具代表性的实验是：作者通过序列、结构和关键功能残基组成的提示，让 ESM3 生成一个新的绿色荧光蛋白 esmGFP。该蛋白与最接近的已知荧光蛋白只有 58% 序列一致性，并在实验中产生与常见 GFP 相近的最终荧光强度。

## 0、网络结构介绍

> 网络主线：序列/结构/功能多轨输入 → 各模态 token 化 → 嵌入求和 → 带几何注意力的双向 Transformer → 多轨输出头 → 迭代去掩码生成 → 可选偏好对齐。

![[esm3.pdf#page=3]]

```text
氨基酸序列 ─────────→ sequence tokens ───────┐
三维结构 ─→ VQ-VAE → structure tokens ──────┤
二级结构、SASA ─────→ property tokens ──────┤
功能关键词、位点注释 → function tokens ─────┤
原子坐标 ───────────→ geometric attention ──┤
                                             ↓
                                共享 Transformer 隐空间
                                             ↓
          ┌──────────────┬──────────────┬──────────────┐
        序列头          结构头          功能/属性头
          └──────────────┴──────────────┴──────────────┘
                                             ↓
                                  迭代解除 mask 完成生成
```

### 0.1 模型解决什么问题

此前 ESM-1/ESM-2 主要把蛋白质当作氨基酸序列建模，结构信息是在隐藏表示中间接出现的。ESM3 进一步要求模型显式处理和生成：

- 蛋白质序列；
- 局部与全局三维结构；
- 二级结构和溶剂可及性；
- 蛋白质功能关键词；
- 残基级功能注释。

因此，ESM3 既可以执行“序列 → 结构预测”，也可以执行“结构 → 序列设计”“功能 → 序列与结构生成”，还可以用部分序列、部分坐标和功能描述共同约束同一次生成。

### 0.2 多模态 token 轨道

ESM3 的主要输入被组织为七条轨道：

1. **sequence**：氨基酸序列；
2. **structure coordinates**：蛋白质主链原子坐标；
3. **structure tokens**：由结构 VQ-VAE 产生的离散结构编码；
4. **SS8**：8 类二级结构；
5. **SASA**：离散化的溶剂可及表面积；
6. **function keywords**：描述活性、结合、酶功能和折叠类型的关键词；
7. **residue annotations**：InterPro 残基级注释。

训练时还使用逐残基和全局平均 pLDDT 置信度轨道；98B 模型在最后 30,000 个训练步骤中加入分类学轨道。

主要 token 化方式如下：

| 轨道 | 表示方式 |
| --- | --- |
| 序列 | 20 种标准氨基酸、4 种非标准符号及特殊 token，共 29 类 |
| 结构 | VQ-VAE 的 4096 项 codebook，加 BOS/EOS/mask/pad |
| SS8 | 8 类二级结构，加 unknown 与 mask |
| SASA | 按频率分为 16 个区间，加 unknown 与 mask |
| 功能关键词 | TF-IDF 后通过 locality-sensitive hashing 量化为每个位置 8 个 token |
| 残基注释 | 1478 维 InterPro multi-hot 特征 |

把不同模态转成 token 的好处是，绝大部分计算都可以使用普通 Transformer 的离散序列建模框架，而不需要为每一种生成方向设计独立网络。

### 0.3 多轨嵌入融合

除原子坐标外，各轨道分别映射为相同维度的逐残基嵌入，然后直接相加：

$$
z_i^{(0)}
=
z_i^{\mathrm{seq}}
+z_i^{\mathrm{struct}}
+z_i^{\mathrm{SS8}}
+z_i^{\mathrm{SASA}}
+z_i^{\mathrm{func}}
+z_i^{\mathrm{res}}
+z_i^{\mathrm{conf}}
$$

某条轨道未知时，用 mask、空注释或零向量表示。所有可用信息在进入 Transformer 时融合进同一个潜在空间。

这种加法融合结构简单、易扩展，但也意味着模型必须自行学习不同轨道的尺度匹配和冲突处理；架构没有显式保证某个输出严格满足所有提示。

### 0.4 Transformer 主干

ESM3 是双向 Transformer，并采用：

- Pre-LayerNorm；
- rotary positional embedding；
- SwiGLU 前馈网络；
- 无 bias 的线性层和 layer norm；
- 在第一个 block 中额外加入 geometric attention。

每层可概括为：

$$
H' = H+s\,\operatorname{MHSA}(H)
$$

$$
H'' = H'+s\,\operatorname{GeoAttn}(H',T)
$$

$$
H^{\mathrm{next}}=H''+s\,\operatorname{SwiGLU}(H'')
$$

其中只有第一层实际启用几何注意力，其余层使用标准注意力和前馈网络。残差缩放系数与总层数有关，用于稳定超深网络训练。

模型训练了三个主要规模：

| 模型 | 层数 | 隐藏维度 | 上下文 | 参数量 |
| --- | ---: | ---: | ---: | ---: |
| ESM3-small | 48 | 1536 | 2048 | 1.4B |
| ESM3-medium | 96 | 2560 | 2048 | 7.7B |
| ESM3-large | 216 | 6144 | 2048 | 98.5B |

作者的内部对照发现，在相近计算预算下增加深度比单纯增加宽度收益更高，因此 98B 模型达到 216 层。

### 0.5 几何注意力

蛋白质每个残基的主链原子可以定义一个局部坐标系：

$$
T_i\in SE(3)
$$

几何注意力把 query 和 key 变换到各残基的局部/全局参考系，通过相对距离和方向计算注意力分数。其设计满足整体旋转和平移不变性：

$$
F(QR+t)=F(R)
$$

其中 $Q$ 是旋转矩阵，$t$ 是平移向量。

普通自注意力只知道 token 之间的统计关系；几何注意力则让模型在给定部分原子坐标时，直接理解不同残基局部框架的相对位置和方向。它只在第一层出现，随后几何信息进入共享隐藏状态，由普通 Transformer 继续处理。

### 0.6 结构 tokenizer 与 decoder

ESM3 使用离散自编码器压缩三维结构：

```text
主链原子坐标
    ↓
局部参考系 + 每个残基的 16 个最近结构邻居
    ↓
几何注意力编码器
    ↓
向 4096 项 codebook 量化
    ↓
每个残基一个 structure token
```

结构 token 不是简单的二级结构类别，而是对残基周围局部三维环境的离散编码。论文报告该 tokenizer 在 CAMEO 上的结构重建 RMSD 小于 0.5 Å。

生成结构 token 后，再使用一个约 700M 参数的后置 Transformer decoder，结合序列 token 和结构 token 重建全原子坐标，并输出 pTM 与 pLDDT。

结构坐标和结构 token 分工不同：

- 坐标通过几何注意力作为高精度条件输入；
- 结构 token 适合作为离散生成目标；
- decoder 把生成的离散结构恢复为连续原子坐标。

### 0.7 功能 token 化

功能关键词数量巨大，而且一个蛋白质可能同时具有多个注释。论文先对关键词进行 TF-IDF 表示，再使用 locality-sensitive hashing（LSH）压缩成固定数量的离散 token。

这一方式允许 Transformer 像预测词汇一样预测功能，但哈希是有损压缩，不同关键词集合可能发生冲突。因此，模型学习的是一种压缩后的功能语义空间，不是严格的一对一功能本体编码。

### 0.8 多轨输出头

Transformer 最后一层表示分别进入浅层 MLP：

$$
z^{(m)}
=
W_{2}^{(m)}
\operatorname{LN}
\left(
\operatorname{GeLU}(W_{1}^{(m)}H)
\right)
$$

每个模态 $m$ 使用独立输出头，预测：

- 氨基酸 token；
- 结构 token；
- SS8；
- SASA；
- 功能关键词 token；
- 残基注释。

共享 Transformer 学习跨模态关系，独立输出头把共享表示翻译回各自词表。

### 0.9 可变掩码率的生成式目标

ESM3 对不同轨道应用随机 mask，训练目标为：

$$
\mathcal L
=
-\mathbb E_{x,m}
\left[
\frac{1}{|m|}
\sum_{i\in m}
\log p_\theta(x_i\mid x_{\setminus m})
\right]
$$

与经典 BERT 固定约 15% mask 不同，ESM3 在 0～100% 之间采样多种遮盖比例，使模型学会：

- 从几乎完整的上下文修复少量 token；
- 从部分序列、结构或功能补全其余模态；
- 从几乎完全遮盖的状态进行生成。

训练中 80% 的情况从均值约为 25% 的 $\operatorname{Beta}(3,9)$ 分布采样 mask 率，20% 从均匀分布采样，总体平均 mask 率约为 30%。较低 mask 率有利于表示学习，较高 mask 率有利于生成；混合噪声计划用于平衡两者。

### 0.10 迭代生成

推理从全部或部分被 mask 的轨道开始。每一轮预测被遮盖 token 的分布，选择部分位置采样并解除 mask，再把更新后的上下文送回模型：

```text
部分序列/结构/功能提示
          ↓
预测所有 mask 位置
          ↓
解除一部分高置信或采样位置
          ↓
重新预测剩余位置
          ↓
直到所需轨道完整
```

由于模型在各种 mask 组合上训练，它不要求固定的从左到右生成顺序，也不限定必须先生成序列或先生成结构。

## 1 将序列、结构和功能统一为可组合提示

ESM3 最核心的能力是任意方向的条件生成。例如：

- 给序列，生成结构和功能；
- 给结构骨架，设计序列；
- 给二级结构和 SASA，生成满足形状要求的序列与三级结构；
- 给催化位点的原子坐标，再给某种 fold 的功能关键词，生成新的支架；
- 给部分序列和部分结构，对剩余区域进行编辑。

作者分别测试各条轨道的提示一致性，使用：

- backbone cRMSD 衡量坐标保持；
- SS3 accuracy 衡量二级结构提示；
- SASA Spearman $\rho$ 衡量暴露度提示；
- InterPro keyword recovery 衡量功能关键词；
- pTM/pLDDT 衡量生成结构置信度。

7B 模型已经能够在各类提示下产生 pTM 大于 0.8 的解。

## 2 结构与功能信息通过 token 化实现统一扩展

很多三维生成模型直接在连续坐标空间中扩散或更新点云，需要专门的等变网络。ESM3 的路线是：

1. 用几何网络把局部结构压缩成离散 token；
2. 用普通 Transformer 大规模建模这些 token；
3. 用结构 decoder 恢复原子坐标。

这使序列、结构和功能能够共享同一种 masked token prediction 目标，也便于扩大参数规模。

代价是模型质量依赖结构 tokenizer：量化会损失信息，tokenizer 或 decoder 的误差也会进入最终结构。虽然论文报告重建误差很小，但“离散 token 合理”与“连续结构在真实环境中稳定”仍不是同一件事。

## 3 规模扩展

最大模型的训练规模为：

- 98.5B 参数；
- 216 个 Transformer block；
- 2.78B 个天然蛋白质来源；
- 数据增强后约 3.15B 条蛋白质序列；
- 236M 个蛋白质结构；
- 539M 个带功能注释的蛋白质；
- 771B 个独特 token；
- 训练过程中约处理 1.8T token；
- 约 $1.07\times10^{24}$ FLOPs。

结构数据不全来自实验。论文大量使用预测结构，并用逆折叠模型为结构生成合成序列。这提高了多模态覆盖率，但意味着训练数据同时继承结构预测器和逆折叠模型的偏差。

扩大模型后，各轨道的负对数似然、表示学习和生成指标均有改善。单序列结构预测中，98B ESM3 在 CAMEO 的 mean LDDT 为 0.895，高于 ESMFold 的 0.865，但仍低于论文所列 AlphaFold2 的 0.904。

## 4 可编程蛋白质设计

ESM3 能组合不同抽象层级的提示。论文展示：

- 固定或部分固定主链坐标；
- 指定 α/β 二级结构布局；
- 指定 SASA 模式；
- 指定结合位点或催化位点的关键原子；
- 指定功能关键词或 fold 类别；
- 在缩短总长度的同时保持活性位点。

例如，作者把天然胰蛋白酶从 223 个残基压缩到 150 个残基，同时提示催化三联体坐标和功能关键词。生成结果保持活性位点的预测 all-atom RMSD 为 0.73 Å，并保留相似 fold。

这种结果展示的是模型在计算预测层面的组合能力，不代表压缩后的胰蛋白酶已经通过催化实验验证。

## 5 生物学对齐揭示大模型的潜在能力

基础模型虽然能响应复杂提示，但并未直接为“高 pTM、低 cRMSD”目标优化。作者为同一个提示生成多个样本，把质量较高的样本和较低的样本组成偏好对，再进行 preference tuning。

在 46 个配体结合基序上，以 128 次生成内是否获得成功结构作为 Pass@128：

| 模型 | 基础模型 | 偏好对齐后 |
| --- | ---: | ---: |
| 1.4B | 9.5% | 18.8% |
| 7B | 19.0% | 37.4% |
| 98B | 26.8% | 65.5% |

成功条件包括：

- backbone cRMSD 小于 1.5 Å；
- pTM 大于 0.8；
- 生成结构能够满足给定的三级配位提示。

对齐后模型不仅成功率上升，还能为同一个 motif 产生更多结构上不同的解。98B 模型的提升尤其明显，支持“更大模型包含更多可被少量偏好数据激活的潜在能力”这一解释。

但评价指标主要来自 ESMFold 等计算模型，偏好训练可能针对代理指标发生过度优化。论文也明确讨论了 surrogate over-optimization 风险。

## 6 esmGFP 的生成过程

### 6.1 提示内容

作者使用基础版 7B ESM3，而不是 98B 模型。目标长度设为 229 个残基，提示包括：

- 形成发色团的 Thr65、Tyr66、Gly67；
- 与发色团形成和催化有关的 Thr62、Arg96、Glu222；
- 起始位置 Met1；
- 天然 GFP 结构中第 58～71 位主链的结构信息。

除这些位置外，其余序列和结构基本从 mask 状态开始。

### 6.2 “思维链”式多阶段生成

论文中的 chain of thought 不是自然语言推理文本，而是多阶段的结构—序列生成流程：

1. 先根据局部活性位点提示生成结构 token，相当于提出一个骨架；
2. 筛选能保持关键原子配位、同时整体结构不同于模板的骨架；
3. 把生成骨架加入提示，再生成氨基酸序列；
4. 在序列和结构之间交替优化；
5. 一旦活性位点配位丢失，就终止该条生成链；
6. 按结构置信度、活性位点几何和序列新颖性筛选候选。

因此，esmGFP 不是一次前向传播直接得到的，而是从数万候选、多阶段筛选和两轮实验中获得。

### 6.3 实验结果

第一轮实验测试 88 个设计，发现低相似度的 B8：

- 与最近已知荧光蛋白约 57% 序列一致；
- 荧光约比天然 GFP 弱 50 倍；
- 发色团成熟需要约一周。

作者以 B8 为新起点继续生成第二轮候选，获得 esmGFP：

- 与 Aequorea victoria GFP 约 36% 序列一致；
- 与最近已知荧光蛋白 tagRFP 为 58% 一致；
- 相对 tagRFP 有 96 个序列位置不同；
- 与最近的天然荧光蛋白 eqFP578 为 53% 一致；
- 两天后达到与测试天然 GFP 相近的荧光强度，但成熟速度仍较慢；
- 激发峰约为 496 nm，发射峰约为 512 nm。

对关键发色团残基进行破坏性突变后荧光消失，支持荧光确实来自预期 GFP 发色团机制。

## 7 “模拟五亿年进化”应如何理解

作者收集天然荧光蛋白的物种分化时间和序列一致性，用一个简单估计器把 GFP 序列差异映射到自然物种分化时间。根据该估计，esmGFP 与最近天然荧光蛋白的差异大致相当于超过五亿年的自然演化距离。

因此，标题中的“五亿年”是一个基于 GFP 序列差异的类比，不表示模型在计算机中逐代模拟了五亿年的种群、突变、选择、遗传漂变和生态环境。更准确的表达是：

> ESM3 一次设计所跨越的 GFP 序列距离，与自然界中经过数亿年分化形成的荧光蛋白距离处于类似数量级。

## 8 论文的核心创新

### 8.1 统一序列、结构和功能的生成模型

ESM3 不再把结构预测、逆折叠和功能预测视为完全独立任务，而是把它们写成同一个多轨 masked completion 问题。

### 8.2 用离散结构 token 扩展三维生成

结构 VQ-VAE 将复杂三维局部环境压缩成 token，使结构生成可以利用标准 Transformer 的扩展能力，同时保留几何注意力对精确坐标条件的支持。

### 8.3 任意组合的提示接口

可变 mask 训练允许用户在不同位置、不同轨道提供不完整约束，为局部编辑、motif scaffolding、结构补全和功能条件设计提供统一接口。

### 8.4 把大语言模型的对齐范式引入蛋白质设计

作者用偏好数据训练模型更好地满足高质量结构和原子配位目标，并发现更大的模型对少量对齐数据响应更强。

### 8.5 对远距离功能蛋白进行湿实验验证

esmGFP 表明模型不仅能生成预测上稳定的结构，还至少可以在一个复杂功能家族中获得远距离、实验可测的功能序列。

## 9 创新点与论文贡献总结

| 类型 | 具体内容 | 是否属于核心创新 |
| --- | --- | --- |
| 多模态表示 | 序列、结构、功能及属性使用多条 token 轨道 | 是 |
| 结构离散化 | VQ-VAE 将局部三维结构编码为 4096 类 token | 是 |
| 几何建模 | 第一层加入 $SE(3)$ 不变几何注意力 | 是 |
| 生成目标 | 在全范围 mask 比例上训练任意条件补全 | 是 |
| 规模扩展 | 1.4B、7B、98B 三个规模和超大多模态数据 | 是重要工程贡献 |
| 生物学对齐 | 用结构质量偏好对进行 preference tuning | 是 |
| 功能验证 | 两轮实验获得远距离荧光蛋白 esmGFP | 是关键实证贡献 |

## 10 对创新点的局限性认识

- 最大 98B 模型训练成本极高，普通研究者难以复现；公开的 ESM3-open 与论文最大模型不是同一规模。
- 训练集包含预测结构和逆折叠生成的合成序列，因此模型也可能继承上游模型的系统性偏差。
- 多数设计评价使用 ESMFold、ESM-IF1 或同一技术谱系的模型，存在代理指标偏差和一定程度的循环验证风险。
- 提示组合实验有时采用“持续采样直到成功”的协议，更适合证明能力存在，不等同于高单次成功概率。
- pTM、pLDDT、cRMSD 和 self-consistency 是计算指标，不能替代折叠稳定性、亲和力和催化活性的实验测量。
- 湿实验的强证据主要集中在 GFP，一个蛋白家族不足以证明模型对所有复杂功能都具有同等生成能力。
- esmGFP 的实验验证证明荧光功能，但论文没有报告其高分辨率实验三维结构。
- “五亿年进化”来自序列一致性与物种分化时间的简化映射，是传播性类比而非真实进化模拟时长。
- 功能关键词和 LSH token 是有损表示；能够恢复关键词不等于真正满足对应生物学功能。
- 生成模型具有潜在双重用途，论文虽然进行了发布审查，但更强的功能条件设计仍需要持续的生物安全治理。

## 一句话概括

> ESM3 的核心创新是把蛋白质序列、三维结构和功能全部离散为可共同遮盖和生成的 token，并在带几何注意力的超大双向 Transformer 中统一建模，使模型能够接受跨模态组合提示、经偏好对齐完成复杂原子约束，并实验生成远离已知序列的荧光蛋白。
